# Learn 3D Printing — Image Assets

These images power the educational sections on the Learn 3D Printing page (`/learn`).
They are **copies of real service/gallery images** so the page shows relevant photos
immediately. Replace any file with a better educational photo using the **same filename**
— no code change needed.

Format: WebP/AVIF/JPG, sRGB, no embedded text/watermark. Palette: white / warm grey /
charcoal / orange `#f78e00`.

## How 3D Printing Works (5-step workflow)
| Filename                             | Step                          |
| ------------------------------------ | ----------------------------- |
| `printing-workflow-cad-model.jpg`    | 1 — Create or obtain a model  |
| `printing-workflow-slicing.jpg`      | 2 — Prepare the file          |
| `printing-workflow-printer-setup.jpg`| 3 — Configure the printer     |
| `printing-workflow-active-print.jpg` | 4 — Print the object          |
| `printing-workflow-finished-part.jpg`| 5 — Finish and inspect        |

2. Save over the matching filename here.
3. No code change needed.
