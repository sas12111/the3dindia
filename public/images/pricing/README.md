# Pricing — Image Assets

These images power the Pricing page (`/pricing`). They are **copies of real service/
material images** so the page shows relevant photos immediately. Replace any file with a
better shot using the **same filename** — no code change needed.

Format: WebP/AVIF/JPG, sRGB, no embedded text/watermark. Palette: white / warm grey /
charcoal / orange `#f78e00`. No fake logos, no identifiable people.

| Filename                      | Where                         |
| ----------------------------- | ----------------------------- |
| `pricing-hero-products.jpg`   | Hero product composition      |
| `material-pla.jpg`            | PLA material card             |
| `material-petg.jpg`           | PETG material card            |
| `material-abs.jpg`            | ABS material card             |
| `material-tpu.jpg`            | TPU material card             |
| `material-nylon.jpg`          | Nylon material card           |
| `material-resin.jpg`          | Resin material card           |
| `instant-quote-products.jpg`  | Quote CTA products            |

## Replacing images
1. Export the real photo at a web-appropriate size.
2. Save over the matching filename here.
3. No code change needed.
