# About Us — Image Assets

These images power the About Us page (`/about`). They are **copies of real service/
material images** so the page shows relevant photos immediately. Replace any file with a
better company photo using the **same filename** — no code change needed.

Format: WebP/AVIF/JPG, sRGB, no embedded text/watermark. Palette: white / warm grey /
charcoal / orange `#f78e00`. No fake logos, no identifiable people presented as staff
unless they are genuine team members.

## Replacing images
1. Export the real photo at a web-appropriate size.
2. Save over the matching filename here.
3. No code change needed.
