# Medical & Anatomical Models — Image Assets

These images power the `/services/medical-anatomical-models` service detail page.

All files below are **placeholders / reused existing assets** and are intended to be
replaced later with real The3DIndia photographs. Keep the **same filenames** when
replacing so no code changes are needed.

Recommended delivery format: **WebP or AVIF**, sRGB, no embedded text/watermark.
Recommended palette: white / light gray / charcoal / orange `#f78e00`, clean studio lighting.

Image rules: models must look like **physical 3D printed educational products**, not
photographs of real human anatomy. No identifiable real patients, no blood, no surgery
scenes, no graphic/disturbing imagery, no fake logos.

1. Export the real photo as WebP/AVIF (or JPG) at the suggested size.
2. Save it over the matching filename in this folder.
3. No code change needed — the page references these paths directly.
