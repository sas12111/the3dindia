# Homepage — Image Assets

These images power the homepage (`/`). They are **copies of the real service hero/
gallery images** so the homepage shows relevant photos immediately. Replace any file
with a better homepage-specific shot using the **same filename** — no code change needed.

Recommended format: WebP/AVIF, sRGB, no embedded text/watermark. Palette: white / warm
grey / charcoal / orange `#f78e00`. No fake logos, no identifiable people.
