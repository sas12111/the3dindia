# Prototyping & Product Development — Image Assets

These images power the `/services/prototyping-product-development` service detail page.

All files below are **placeholders / reused existing assets** and are intended to be
replaced later with real The3DIndia photographs. Keep the **same filenames** when
replacing so no code changes are needed.

Recommended delivery format: **WebP or AVIF**, sRGB, no embedded text/watermark.
Recommended palette: charcoal / white / metallic gray / orange `#f78e00`, studio lighting.
Prototypes must look genuinely 3D printable. No identifiable people, no fake logos.
