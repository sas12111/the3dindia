# Customized Gifts & Personalized Items — Image Assets

These images power the `/services/customized-gifts` service detail page.

All files below are **placeholders / reused existing assets** and are intended to be
replaced later with real The3DIndia product photographs. Keep the **same filenames**
when replacing so no code changes are needed.

Recommended delivery format: **WebP or AVIF**, sRGB, no embedded text/watermark.
Recommended palette: warm neutral / charcoal / orange `#f78e00`, warm lifestyle lighting.
Products should look genuinely 3D printed. No identifiable real people, no fake logos.

1. Export the real photo as WebP/AVIF (or JPG) at the suggested size.
2. Save it over the matching filename in this folder.
3. No code change needed — the page references these paths directly.
