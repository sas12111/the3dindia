# Portfolio — Image Assets

These images power the Portfolio page (`/portfolio`). They are **copies of the real
service/gallery images** so the portfolio shows relevant photos immediately. Replace any
file with a better project photo using the **same filename** — no code change needed.

Recommended format: WebP/AVIF, sRGB, no embedded text/watermark. Palette: charcoal /
white / warm grey / orange `#f78e00`. No fake logos, no identifiable people.

## Replacing images
1. Export the real photo at a web-appropriate size (WebP/AVIF or JPG).
2. Save over the matching filename here.
3. No code change needed.
