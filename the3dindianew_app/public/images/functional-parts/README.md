# Functional Parts & Utility Products — Image Assets

These images power the `/services/functional-parts` service detail page.

All files below are **placeholders / reused existing assets** and are intended to be
replaced later with real The3DIndia product photographs. Keep the **same filenames**
when replacing so no code changes are needed.

Recommended delivery format: **WebP or AVIF**, sRGB, no embedded text/watermark.
Recommended palette: black / dark gray / white / orange `#f78e00`, workshop lighting.
Parts should look genuinely printable on desktop/prosumer FDM. No identifiable people, no fake logos.
